# Fadi Farook Website

Personal academic website for `fadifarook.com`, built with Jekyll and based on the al-folio theme.

## Main Content

- Home page: `_pages/about.md`
- Research page: `_pages/projects.md`
- CV link/page: `_pages/cv.md`
- Current CV PDF: `assets/pdf/Fadi_CV.pdf`
- Main config: `_config.yml`

## Local Build

Install Ruby dependencies once:

```sh
bundle install
```

Run locally:

```sh
bundle exec jekyll serve
```

Then open the local URL printed by Jekyll, usually `http://127.0.0.1:4000`.
